# APEX Formation Lens — TradingView

Исходник визуального индикатора на Pine Script v6: [ApexFormationLens.pine](ApexFormationLens.pine).

## Установка

1. Откройте график в TradingView и панель **Pine Editor**.
2. Создайте новый индикатор, замените содержимое редактора полным кодом из `ApexFormationLens.pine`.
3. Нажмите **Save**, затем **Add to chart**.
4. В настройках выберите модель анализа: **Swing**, **Intraday** или **Scalp**. Режим таблицы **Quick** показывает краткий сценарий; **Full** — подробный контекст.
5. Если после обновления осталась старая панель, удалите прежний экземпляр индикатора с графика и добавьте сохранённый скрипт заново.

## Что показывает

- EMA 20/50/200, сессионный UTC VWAP с одной парой полос отклонения и необязательный Supertrend.
- Подтверждённые зоны поддержки/сопротивления старших таймфреймов, уровни предыдущего дня и границы азиатского диапазона.
- Локальные кандидаты Order Block и FVG, закрытые события BOS/CHoCH, возврат за уровень (`R`).
- RSI(14), пересечения его порогов и дивергенции по подтверждённым ценовым пивотам.
- Объём, его среднее, полосу направления EMA, компактную оценочную зону `VOL≈`, сессии и относительное движение к BTC.
- Таблицу контекста с русскими условными сценариями: что наблюдается и какого подтверждения ждать.

Роли таймфреймов зависят от выбранной модели:

| Модель | Направление | Зона | Триггер |
|---|---|---|---|
| Swing | 1W | 1D | 4H |
| Intraday | 1D | 4H | 15m |
| Scalp | 4H | 15m | 5m |

Отдельные визуальные элементы имеют ограничения по таймфрейму и могут быть скрыты настройками. Пивоты становятся известны только после закрытия подтверждающих свечей справа. Статус «УСЛОВИЯ ЕСТЬ» означает выполнение локальных условий индикатора для ручной проверки.

## Маркеры событий APEX

Pine не загружает историю событий из API бота автоматически. Для точных маркеров вставьте подготовленный экспорт сохранённых событий в поле **Apex events: paste export for this symbol**, по одной строке:

```text
SYMBOL|confirmed_ms|reference_price|G/O|BUY/SELL|4H|zone|reason
```

Здесь `confirmed_ms` — Unix-время в миллисекундах, `reference_price` — сохранённая опорная цена; остальные поля описывают класс и контекст события. `SYMBOL` должен совпадать с символом открытого графика без суффикса `.P`. Обрабатываются первые 200 строк.

- **G / GOLDEN:** сохранённое строгое событие с подтверждённой отправкой Telegram; такой класс должен быть проверен при подготовке экспорта.
- **O / ORDINARY:** сохранённое обычное наблюдение dashboard.
- **A** и **R:** самостоятельные локальные наблюдения графика, а не импортированные сигналы бота.

Без экспорта счётчики импортированных событий остаются нулевыми. Класс GOLDEN не означает доказанную прибыльность или исполненную сделку.

## Границы применения

Индикатор предназначен для визуального исследования и ручного анализа. Он не выставляет ордера и не воспроизводит полный движок решений APEX. Его EMA, данные и локальные зоны могут отличаться от расчётов бота.

`VOL≈` оценивает распределение объёма по младшим OHLCV-свечам. Это не стакан, не реальные ликвидации, не footprint и не точный CVD. Локальный Order Block — ценовая модель, а не доказательство институциональных заявок.

Это `indicator()`, а не `strategy()`: встроенного бэктеста сделок, проверенной доходности и полноценного расчёта ТВХ/SL/TP здесь нет. Размещение исходника на GitHub не публикует индикатор в каталоге TradingView.
