## Что это за проект (один абзац)

«Пульс» — исследовательская платформа проверки торговых гипотез на крипто-
фьючерсах Bybit (~500 перпов), НЕ «бот с доказанным эджем». Эдж пока НЕ
доказан — идёт боевой период (заморозка правил) с форвард-экзаменами.
Главный актив — процесс: гипотеза → детерминированная реализация →
заморозка → независимый форвард → вердикт по заранее записанным порогам →
убитое удаляется. Уже похоронено 8 гипотез (bias v1 39%, LLM-скоринг,
AVEA-81, squeeze_radar, «эдж направления», pump-лонги при funding<0,
«+R как бета», предикторы магнитуды на n=2400). Смерть идеи = штатный исход.

## ЖЕЛЕЗНЫЕ ПРАВИЛА (нарушение = отравленные данные)

1. **Честное окно**: аналитика resolved.csv только run_ts ≥ 2026-06-02.
2. **Время**: naive ts в пайплайне = UTC. Направления бывают кириллицей
   (ЛОНГ/ШОРТ), латиницей (long/short), up/down — нормализуй при чтении.
3. **Анти-look-ahead**: вход = close ПЕРВОГО ПОЛНОГО бара после сигнала,
   peak/dd строго с bars[1:] (бар входа выброшен) — ЕДИНАЯ методика везде
   (ledger, rose_history, diary, entry-лог, фронт). НЕ «чинить» её.
4. **Волны**: сигналы одного 5-мин скана коррелированы → в экзаменах кластер
   = 1 кейс; в зоне ≥5 non-awakening одного скана скрываются.
5. **Дневник — три замка**: expectation замораживается при рождении и НЕ
   переписывается; вердикты только при n_class≥10 и только по final;
   сюрпризы копятся, но НЕ меняют правила.
6. **Правила рождаются одним путём**: ретро-валидация → observe 🧪 (дашборд,
   без TG) → боевое, с порогом принятия И критерием отказа ДО старта.
   Ретро-p-value ≠ доказательство (86% стало 68% на квази-OOS).
7. **Секреты**: channels_config.json (Telethon), rose_history.json (посты
   платного канала), push_*.json — НИКОГДА в git/фид/публичный снапшот.
   Публичный снапшот кода — ТОЛЬКО руками брата (tools/update_public_repo.sh).
8. **Не трогать без явного добра**: TG-доставку, боевые гейты скринера
   (PumpWatchGate, ShortDistMute), методику 6ч/24ч, пороги радара.
9. **Классификатор** заблокирует: секреты в облако, внешние публикации,

## Стиль работы с братом

Звать «брат», тепло, по-русски. ЦИФРЫ только из выполненного кода с
сохранённым выводом (no fabrication; вывод исследований — в
outcomes/studies/*.txt). Прогнозы предрегистрируй до исхода. «Не знаю /
данных мало» — валидный ответ. На «что думаешь» — анти-sycophancy:
стилмен за/против, confidence, несогласие прямо. Ponytail: минимум кода,
YAGNI, но НИКОГДА не лениться на валидации границ/деньгах/времени.
Нетривиальная логика оставляет selfcheck. После правок кода демонов —
юниты + kickstart резидентных. Внешние действия (публикация, деплой чужих
доменов) — только руками брата. Брат любит ultrathink на развилках — думай
глубоко, отвечай ясно, лид с вывода.
