# Чеклист: что делает скринер (screener.py)

## Источник данных
**Bybit V5 Public API** — без API ключей, только публичные эндпоинты.
Только USDT Linear Perpetuals (бессрочные фьючерсы).

---

## Что бот анализирует по каждой паре

### Базовые метрики (из тикера — 1 запрос на все пары)
- [ ] **Топ-N пар по объёму** — сортировка по turnover24h, берёт топ-50
- [ ] **Funding Rate** — текущий % (отрицательный = шорты платят лонгам = бычий сигнал)
- [ ] **Open Interest** — текущий OI + изменение за 24h (через историю по 1h)
- [ ] **Позиция цены в 48h диапазоне** — где цена между хаем и лоем последних 48 часов (0% = дно, 100% = вершина)
- [ ] **Всплеск объёма** — текущий объём vs средний за предыдущие свечи (×2 = аномально)

### Продвинутые метрики (отдельный запрос на каждую пару)
- [ ] **Long/Short Ratio** — соотношение лонг/шорт позиций у топ-трейдеров Bybit (период 1h)
- [ ] **CVD (Cumulative Volume Delta)** — из последних 500 реальных сделок с Bybit. Тейкер-покупки минус тейкер-продажи. CVD+ = бычья агрессия преобладает, CVD- = медвежья
- [ ] **HTF тренд (4H структура)** — определяет тренд по свинг-хаям и свинг-лоям на 4H свечах: `bull` / `bear` / `range`
- [ ] **FVG (Fair Value Gap)** — поиск незакрытых 3-свечных гэпов на 1H за последние 40 свечей. Бычий FVG: high[i-2] < low[i]. Медвежий FVG: low[i-2] > high[i]
- [ ] **Order Block (OB)** — последняя медвежья свеча перед бычьим BOS (и наоборот). Показывает зону, откуда крупный игрок входил в позицию
- [ ] **Sweep (ложный пробой)** — проверяет, пробила ли последняя свеча хай/лой предыдущих 10 свечей и закрылась ли обратно внутри диапазона
- [ ] **Ликвидационные события (аппроксимация)** — ищет в истории OI свечи с резким падением OI (> 3%) + всплеском объёма (> 2×) + движением цены (> 1%). Это приблизительная оценка, **не реальный хитмап ликвидаций**
- [ ] **DOM: дисбаланс стакана** — снимок стакана (50 уровней). Считает суммарный объём бидов vs асков в USD. Положительный % = давление покупателей
- [ ] **DOM: крупные стены** — ордер считается стеной, если он в 3× больше среднего ордера на своей стороне
- [ ] **DOM: завалы (stacked walls)** — ≥2 крупных лимитки одной стороны в пределах 1.2%. Вход за 0.2–0.5% до 1-й, стоп за 2-ю пачку. Флаги `завал↓×N` / `завал↑×N`, приоритет выше одиночной стены.
- [ ] **R:R floor (⚠)** — при R:R < 2 значение в watchlist помечается `⚠`. PDF: целевой R:R от 1:3.75 для раскачки.

## Сетапы, которые ищет бот

### Сетап 1 — Ликвидационный сквиз
Бот начисляет очки за:
- [ ] Funding Rate отрицательный (лонгам платят, шорты перегреты)
- [ ] Цена в нижней части 48h диапазона (< 35%)
- [ ] OI упал за 24h на > 5% (ликвидации прошли, позиции расчищены)
- [ ] Обнаружены лонг-ликвидационные события в истории
- [ ] HTF тренд бычий (4H)
- [ ] Рядом незакрытый бычий FVG (< 2% от цены)
- [ ] Рядом бычий Order Block
- [ ] CVD положительный при цене у дна
- [ ] Дисбаланс стакана в пользу бидов

**Логика:** шорты накопились → платят funding → цена у поддержки → сквиз вверх

### Сетап 2 — BOS + FVG / Order Block
Бот начисляет очки за:
- [ ] Объём в 1.5×+ выше среднего (было движение)
- [ ] OI вырос на > 5% за 24h (новые позиции открылись)
- [ ] Цена откатила в середину диапазона 30–70% (зона FVG/OB)
- [ ] L/S Ratio > 1.5 у топ-трейдеров
- [ ] Есть незакрытый FVG рядом с ценой (< 3%)
- [ ] Есть Order Block рядом с ценой
- [ ] HTF тренд не рейндж

**Логика:** пробой структуры + откат в зону → вход по тренду

### Сетап 3 — Рейндж Sweep
Бот начисляет очки за:
- [ ] Последняя свеча пробила хай или лой предыдущих 10 свечей и закрылась обратно (sweep)
- [ ] Цена у крайней границы 48h диапазона (< 15% или > 85%)
- [ ] Funding не согласован с позицией цены (платят не те)
- [ ] Ликвидационные события после sweep (подтверждение)
- [ ] Дисбаланс стакана против направления sweep

**Логика:** рынок забрал ликвидность за уровнем → разворот к противоположной стороне

## Колонки в выводе

| Колонка | Что означает |
|---------|-------------|
| Пара | Тикер (BTCUSDT и т.д.) |
| Цена | Последняя цена |
| Fund | Funding Rate в % (отрицательный = бычий) |
| OI24h | Изменение Open Interest за 24h |
| Поз% | Где цена в 48h диапазоне (0% = дно, 100% = вершина) |
| Vol | Во сколько раз текущий объём выше среднего |
| HTF | Тренд на 4H: bull / bear / range |
| FVG | Количество незакрытых FVG зон |
| OB | Количество Order Block зон |
| CVD | CVD из последних 500 сделок (+ = бычий) |
| DOM | Дисбаланс стакана (+ = больше бидов) |
| Sweep | ↓ = sweep снизу, ↑ = sweep сверху, — = нет |
| Liq | L = лонг-ликвидации замечены, S = шорт-ликвидации |
| Score | Итоговый балл (чем выше — тем чище сетап) |
| Заметки | Конкретные условия, которые сработали |

## Что бот НЕ делает (ограничения)

- [ ] **Реальный хитмап ликвидаций** — нужен Coinglass API key. Текущая аппроксимация через OI drop — это грубая замена, не точные кластеры
- [ ] **CVD в реальном времени** — бот делает снимок последних 500 сделок, а не отслеживает CVD непрерывно
- [ ] **Absorption в стакане** — чтобы видеть поглощение, нужно отслеживать стакан во времени (WebSocket). Статический снимок не показывает поглощение
- [ ] **Tape (лента сделок) в реальном времени** — нет WebSocket, только снимок последних сделок
- [ ] **HTF на Daily/Weekly** — сейчас только 4H. Добавить Daily легко
- [ ] **Алерты в Telegram** — нет уведомлений при появлении сигнала
- [ ] **Автообновление** — запускается вручную

## Сетап 4 — Breakout / Pre-Pump (новый)

**Цель:** заходить ДО или В САМОМ НАЧАЛЕ пампа, а не после.

### Детекторы раннего пампа

- [x] **ATR Compression** — текущий ATR ÷ исторический ATR (40 свечей). Значение < 0.65 = пружина заряжена. < 0.50 = экстремальное сжатие перед взрывом. В выводе: `⊕ATR0.42`
- [x] **OI Coil** — OI вырос >4% за 12h, а цена стояла в диапазоне <2%. Классика тихого набора позиции крупным игроком до пампа. В выводе: `⊕OIcoil`
- [x] **CVD-Price Divergence** — CVD >+15% (покупают агрессивно), но цена не выросла. Это скрытое накопление — цена «догонит» CVD вверх. В выводе: `⊕CVDdiv`
- [x] **Volume Acceleration** — объём нарастает на зелёных свечах в последних 6 свечах (ratio > 1.4). Импульс набирается прямо сейчас. В выводе: `⊕vol×1.7`
- [x] **Whale Activity** — одна сделка ≥8× среднего размера в последних 100 трейдах. Институционал вошёл рыночным ордером. В выводе: `⊕кит×23`

### Где смотреть результаты

| Место | Что показывает |
|-------|---------------|
| **MARKET SNAPSHOT → ⊕ PRE-PUMP РАДАР** | Топ-3 пары по pump_score среди всех анализируемых (порог ≥ 40) |
| **Таблица каждого сетапа → колонки ⊕Pump / ⊕Sig** | pump_score и сработавшие сигналы для каждой пары |
| **Deep Dive** | Полные объяснения ATR Compression, OI Накопление, CVD Дивергенция, Разгон объёма, Кит в ленте |
| **Флаги (⊕ префикс)** | Быстрый взгляд: ⊕ATR, ⊕OIcoil, ⊕CVDdiv, ⊕vol×N, ⊕кит×N |

### Логика сетапа 4 (scoring)

Максимальные веса:
- ATR Compression: 38 pts
- OI Coil: 32 pts
- CVD Divergence: 30 pts
- Volume Acceleration: 26 pts
- Whale Buy: 22 pts
- OI strong_bull: 20 pts
- RS > 1.8x: 18 pts
- Volume spike (vol_ratio): 18 pts
- HTF bull: 14 pts
- Funding: до 14 pts

Порог срабатывания: pump_score ≥ 40 (в PRE-PUMP РАДАРЕ)

## Запуск

```bash
cd ~/Desktop/трейдинг
python3 screener.py
```

Примеры:
```bash
python3 screener.py --top-n 30 --min-score 45
python3 screener.py --top-n 20 --watchlist-size 3 --deep-dive-size 2
python3 screener.py --export-json --export-csv
```

Параметры в конце `screener.py`:
```python
run_screener(top_n=50, min_score=35)
# старый запуск всё ещё работает,
# но теперь те же параметры можно передавать через CLI
```

Время работы: ~60–90 секунд на 50 пар.

## Исправления и улучшения (Апрель 2026)

### 🐛 Исправленные баги

- [x] **RSI — сглаживание Уайлдера (SMMA)**: было простое среднее → теперь экспоненциальное сглаживание, как в оригинальном RSI Уайлдера. Значения RSI и дивергенции теперь точнее.
- [x] **RSI Дивергенция**: встроенный расчёт RSI тоже исправлен на SMMA.
- [x] **Inside Bar фильтр**: добавлено условие — baby bar должна быть ≤70% mother bar. Исключены ложные inside_bar на практически одинаковых свечах.

### ✨ Новые паттерны

- [x] **Doji** — тело ≤8% диапазона, оба хвоста ≥35%: нерешительность рынка / разворот
- [x] **Gravestone Doji** — тело у дна, верхний хвост ≥75%: медвежий разворот на хае
- [x] **Dragonfly Doji** — тело у верха, нижний хвост ≥75%: бычий разворот на дне (засчитывается как бычий паттерн)

### ✨ Новые функции

- [x] **detect_funding_extreme** — детектор экстремального funding rate:
  - `extreme_neg` (< -0.08%): редчайший сквиз-триггер (+25 к Setup 1, +18 к Setup 4)
  - `high_neg` (< -0.05%): сильное шорт-давление (+14 / +10)
  - `period_min`: минимум за ~3 дня (+8)
  - `extreme_pos`/`high_pos` (> +0.05/0.08%): штраф (−15 / −12)

- [x] **detect_absorption** — статическое поглощение (объём >2.5× медианы, тело ≤1.5%):
  - `bull_absorb`: цена падала + аномальный объём без движения → крупный покупатель (+16 к Setup 1, +18 к Setup 4)
  - `bear_absorb`: цена росла + аномальный объём → крупный продавец (штраф)
  - ⚠️ Это снимок, а не реал-тайм наблюдение. Для точного поглощения нужен футпринт.
