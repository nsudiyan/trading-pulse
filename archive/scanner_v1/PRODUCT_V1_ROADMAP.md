# Вариант 1 — «Сканер волатильности + TA-ассистент» — РОАДМАП

**Позиционирование (честное, не обсуждается):** инструмент ПОИСКА движений + ОБУЧЕНИЯ.
НЕ торговые сигналы, НЕ финсовет, НЕ обещание прибыли. Причина — у бота нет доказанного
net-of-costs эджа (см. memory `project_bot_strengths_2026-05-31`). Это защищает аудиторию и репутацию.

---

## ✅ СДЕЛАНО (2026-05-31, протестировано на живых данных)

**`scanner_assistant.py`** — ядро продукта (чистые функции, дисклеймер везде, без BUY/SELL/TP/SL):
- `/start` — онбординг + дисклеймер (что делаю / чего НЕ делаю)
- `/scan [vol|funding|oi|volume]` — курирование по линзам ПО ЗАПРОСУ (решает флуд ~58/день), «кандидат + ПОЧЕМУ в списке»
- `/chart SYMBOL` — живой TA с биржи (тренд/RSI/ATR/уровни, на ЗАКРЫТЫХ свечах, без look-ahead)
- `/macro` — режим рынка (Fear&Greed, доминация BTC, потоки стейблов) + описательное чтение
- `/learn funding|oi|atr|cvd` — образовательные пояснения метрик

**`scanner_bot_run.py`** — мульти-юзерный раннер (отдельный токен, polling, rate-limit, онбординг на /start).
Изолирован от живого `telegram_bot.py`. Без токена — печатает инструкцию и выходит (ничего не ломает).
