## Как пользоваться

1. Терминал → `cd ~/Desktop/трейдинг && claude`
2. **Один этап = одна сессия.** После этапа — `/clear` (или новая сессия). Так контекст не замусоривается.
3. Порядок: **0 → 1 → 2 → 3 → 4** (P0, по порядку) → **5–8** (P1, можно в любом порядке) → **9–10** (P2) → **11** (финал).
4. После каждого этапа смотри `git log --oneline -3` и `git diff HEAD~1` — всё откатывается через `git revert`.
5. Если Claude Code скажет «факт из промпта не сходится с кодом» — это нормально, код менялся. Верь коду.
6. Для этапа 3 (самый большой) — сначала попроси план (plan mode: Shift+Tab) и прочитай его, потом разрешай править.
