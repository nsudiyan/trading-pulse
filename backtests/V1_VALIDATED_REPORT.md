## Методология

- **Baseline score** = оригинальный `score` из CSV (ручная настройка)
- **V1 adjusted score** = `score + Σ(signal_weight × flag)` где веса из `calibration/signal_weights.json`
- **Метрики:** ЛОНГ-трейды, decisive outcomes (TP1/WIN = win, STOP/LOSS = loss, FLAT исключён)
- **Precision** = Win Rate в группе (= доля WIN/TP1 среди decisive)
- **Recall** = доля суммарных WIN-сделок, попавших в группу
- **Lift** = WR_group / WR_baseline − 1
- **Регрессия** = если V1+ WR ниже baseline WR на >3pp
- **OOS подтверждение** = n ≥ 20 при флаге = 1
